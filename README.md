# AI & ML Internship – Task 2  
## Data Cleaning & Missing Value Handling

### 📌 Overview
This repository contains Task 2 of the AI & ML Internship, focused on cleaning datasets and handling missing values using Python.

---

### 🛠 Tools Used
- Python
- Pandas
- NumPy
- Jupyter Notebook

---

### 📁 Dataset
- House Prices Dataset  
  *(or Medical Appointment No Shows Dataset)*

---

### 🔍 Task Objectives
- Identify missing values
- Visualize missing data patterns
- Apply mean/median imputation for numerical columns
- Apply mode imputation for categorical columns
- Remove columns with excessive missing data
- Validate dataset after cleaning
- Compare dataset quality before and after cleaning

---

### 🧪 Steps Performed
1. Loaded dataset and inspected missing values
2. Visualized missing data using bar charts
3. Handled numerical missing values using mean/median
4. Handled categorical missing values using mode
5. Removed columns with high missing percentages
6. Validated cleaned dataset
7. Compared dataset size before and after cleaning

---

### 📊 Final Outcome
The dataset was successfully cleaned and prepared for machine learning, ensuring improved data quality and reliability.
